Deploying to Netlify Guide

Publish this interactive tutorial & compiler live on the web in seconds using Netlify.

1

Save as `index.html`

Copy the entire single-file code of this application and save it locally on your computer as a file named index.html.

2

Go to Netlify Drop

Netlify Drop allows you to publish static sites instantly without setting up Git repositories or complicated build pipelines.

Open Netlify Drop
3

Drag & Drop to Publish

Drag your folder containing index.html right into the Netlify Drop browser zone. Your site is live instantly!

✨ Free SSL & Custom Domain support included

Pro Tip: CLI Deployment

If you prefer using the command line via Netlify CLI, run the following commands in your terminal:

npm install netlify-cli -g
netlify login
netlify deploy --prod
